# 🔬 Derma Intel — Guntur

A **dermatologist search-intelligence dashboard** for Guntur, Andhra Pradesh. It turns 50 high-intent
Google searches into a competitive map of local skin clinics, scores each clinic on a **Vulnerability
Index (0–100)**, and surfaces the 10 clinics with the weakest online presence (your best opportunities).

> **100% free — no API keys, no paid services.**
> - Search queries are generated by **you** in any free AI tool (ChatGPT / Claude / Gemini), via a
>   prompt the app hands you — then pasted back in.
> - Map data is collected by **free Google Maps scraping** (Playwright) — the same source as the paid
>   Places API, so the same accuracy.

---

## What you get

- **Tab 1 — Queries:** paste-in workflow + a sortable/filterable table of all 50 queries (category,
  intent, and search-strength auto-derived from each query).
- **Tab 2 — Maps Results:** 3-panel browser — query list → clinic cards → full clinic detail with a
  live vulnerability pre-score.
- **Tab 3 — Analytics:** 14 interactive charts (donut, scatters, histogram, box, heatmap, treemap,
  OpenStreetMap map, competitive quadrant, presence funnel, …).
- **Tab 4 — Vulnerable 10:** ranked cards + an auto-written opportunity note per clinic, with **Excel**
  and **one-page PDF** export.

All three spreadsheets (`search_queries_50.xlsx`, `google_maps_results_50.xlsx`, `vulnerable_10.xlsx`)
open cleanly in Excel and Google Sheets.

## Setup (one time)

Requires **Python 3.10+**.

```bash
pip install -r requirements.txt
python -m playwright install chromium     # only needed for LIVE scraping (see note below)
```

## Run

```bash
streamlit run app.py
```

Then in the browser:

1. **Tab 1 →** copy the prompt → paste it into any free AI tool → paste its answer back → **Parse & Save**.
2. **Sidebar →** click **▶ Run Pipeline**.
   - Want to see the whole dashboard *instantly* without scraping? Flip **“Use mock data”** first.
3. Explore the tabs and download the Excel / PDF exports.

Results are cached to disk, so re-launching the app reloads everything without re-scraping.

---

## “Use mock data” mode

The sidebar has a **Use mock data (no scraping)** toggle. It fills the dashboard with realistic sample
clinics so you can explore every chart, score, and export **without a browser or network** — handy for a
quick demo or if Chromium isn’t installed yet.

---

## Live scraping & the Chromium download

Live Google Maps scraping needs Playwright’s Chromium browser (`python -m playwright install chromium`).

On some networks (corporate proxies / antivirus that inspect TLS) this download fails with
`UNABLE_TO_VERIFY_LEAF_SIGNATURE`. Safe fixes, best first:

1. Run the install command on a network **without** TLS interception (e.g. a home network / phone hotspot).
2. Point Node at your organisation’s root certificate:
   `setx NODE_EXTRA_CA_CERTS "C:\path\to\corporate-root-ca.pem"` then re-run the install.
3. Temporarily disable HTTPS/SSL scanning in your antivirus for the one-time download.

Until Chromium is installed, the app is fully usable in **mock data** mode.

> **Note on scraping:** scraping Google Maps is against Google’s Terms of Service and is more fragile than
> an official API. This project keeps volume low (≈50 queries), adds polite delays, caches aggressively,
> and degrades gracefully. Use it responsibly for your own market research.

## Project structure

```
app.py                  # Streamlit entry point (sidebar + pipeline + 4 tabs)
config.py               # All constants + scraper settings (no keys)
modules/
  query_generator.py    # Prompt builder + robust paste parser + xlsx
  maps_collector.py     # Playwright scraper + mock mode + OSM fallback + xlsx
  analytics.py          # Data-prep helpers + 14 chart builders
  vulnerability.py      # 0–100 scoring + opportunity notes + top-10 export
  storage.py            # JSON state store (reload without re-scraping)
components/             # One file per tab
data/                   # Generated .xlsx exports
.cache/                 # Scrape cache + app state
tests/                  # pytest suite (run: python -m pytest)
```
