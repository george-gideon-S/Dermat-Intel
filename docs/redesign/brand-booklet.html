Categorical — each hue is a thing

The rainbow, fixed order, ≤6 hues per view. Hue distinguishes categories: an intent, a clinic type, a presence-type.

Sequential — hue is magnitude

The opportunity score only. Amber → clay encodes low → high. The top stays clay, never alarm-red — diagnostic, not accusatory.

12 · Don'ts
✗ Pure-white background — use oat
✗ Inter / Roboto / system display
✗ Italic or ALL-CAPS headers
✗ Proportional figures — numbers are mono
✗ >6 hues / rainbow for a magnitude
✗ Alarm-red opportunity top — use clay
✗ Sharp 0–4px corners in the rounded system
✗ Hard-coded hex/px — reference tokens
