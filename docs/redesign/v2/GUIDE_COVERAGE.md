# Brand Guide v2 — Coverage Checklist

Derived from `design/Brand Identity Design Samples/` (FPA-v2026, 48pp · Optty-2025, 18pp).
Borrowing their **completeness and rigor**, not their aesthetics. This decides what
`BRAND_GUIDE_V2.md` / `brand-guide.html` / the booklet must and must not contain.

| Sample section (FPA / Optty) | v2 needs it? | Why / how it lands for Derma Intel |
|---|---|---|
| Guideline intro + "how to use this" (FPA 0) | **Yes, brief** | One paragraph: purpose = "every output distinctly Derma Intel", audience = future sessions + collaborators. |
| Brand story / what-is (FPA 1.0, Optty p2) | **Yes** | Essence + the three carried-over principles. **Steal Optty's move:** the motif is a metaphor — grain field = the noisy market of patients searching; crisp dot numerals + ruler ticks = the clarity we extract. Texture is meaning, not decoration. |
| Personality spectrum sliders (FPA 1.1) | **Yes** | Compact voice definition: Calm↔Energetic, Clinical↔Warm, Confident↔Boastful, Premium↔Flashy, Data↔Story — with our dot marked on each. Includes the **clinical-mirror language** rule. |
| Logo versions + symbolism (FPA 2.1, Optty icon story) | **Yes, compact** | Wordmark + tile mark + the v2 accent treatment; one paragraph of symbolism (the dot = a data point = a patient searching). |
| Minimum sizes + clear space (FPA 2.2–2.3, Optty p12) | **Yes, one panel** | Keep v1's numbers unless v2 mark changes them. |
| Endorsement / extreme edge placement (FPA 2.4) | **No** | We have no wall installations or street posters. Noted as deliberate omission. |
| Modular logo — which version when (Optty p7) | **Yes, table row** | 3 contexts: nav (mark), page header (wordmark), favicon (mark). |
| Social media icon spec (Optty p8) | **No** | No social presence yet; add when it exists. |
| Product / sub-brand logos (Optty p11) | **No** | Single product. Tier names are typography, not logos. |
| Logo misuse gallery (Optty p13, FPA 5.3) | **Yes** | ≥8 do/don't pairs — logo AND component misuse (e.g. grain gradient behind body text, rainbow numerals, liquid-glass behind charts). |
| Neutral palette + named colors (FPA 3.0, Optty p15) | **Yes** | Canvas/ink/lime + the three **meaning-named triads** (Growth, Status, Alert). Full value tables (hex only — no print PMS/CMYK needed for a digital product; booklet gets hex+RGB). |
| Proportional color use pie (FPA 3.1) | **Yes** | Canvas ~70% · surface ~20% · ink ~8% · lime+triads ~2%. This single diagram enforces restraint. |
| Gradient accent tiers (FPA 3.1) | **Adapted** | Our version = the grain-gradient recipe itself (stops, blur, grain opacity) + intensity-as-magnitude rule. |
| Typeface roles + settings (FPA 4.x, Optty p17) | **Yes** | Geist (UI/body) · Doto ROND 100 (hero numerals ONLY) · Geist Mono (labels/table numerals). Type scale + line-height/tracking table + "never Doto for words" rule. |
| Serif alternative (FPA 4.3) | **No** | No serif in the system. |
| Geometry & shape dynamics (FPA 5.0–5.2) | **Yes, merged** | The "curved boxy" radii system + pill logic + ruler-tick geometry as one section. |
| Motion curves (FPA 5.4) | **Yes** | First-class chapter: durations/easings tokens, count-up + tick-draw signatures, reduced-motion first-class, liquid-glass usage map. |
| Icon & icon library (FPA 6.x) | **Yes, minimal** | Rule-based (stroke 1.5px, rounded caps, 20/24px grid, ink or ink-2 only) + the ~12 icons the product actually uses. No speculative library. |
| Examples / applications (FPA 7.0) | **Yes** | Live components ARE the examples (guide is built in the system) + one dashboard styleframe + one booklet spread. |
| Chart styling rules | **Yes (ours, no sample equivalent)** | ECharts doctrine: categorical = triad identities, magnitude = intensity, grid = line-2, tooltip = glass pill. The samples have no data-viz — we are a data product; this chapter is mandatory. |
| Accessibility | **Yes (ours)** | Contrast table (white-on-triad, ink-on-lime), focus states, reduced-motion. Samples omit it; we don't. |
| Closing note (FPA 8.0) | **Yes, 3 lines** | Why design rigor sells a diagnostic product. |

**Structural patterns adopted:** numbered chapters with running footer folios (both samples) ·
bilingual-style short/long text rhythm (FPA) becomes short-rule + expanded-rationale rhythm ·
"do NOT" imperatives verbatim style (Optty) · every chapter opens with a one-sentence purpose.
