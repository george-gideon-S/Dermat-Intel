05

Typography — three faces, three jobs

Geist · words Trusted in person. Invisible online.
Doto · hero numerals 0123456789
Geist Mono · labels SEARCHES TRACKED · 47 REVIEWS VS 212 MEDIAN
Scale Aa Aa Aa Aa Aa AA

Doto is numerals ONLY — never words, never body, always font-variation-settings: var(--dot-round). The huge size contrast between a hero numeral and its micro-label is a brand signature — don't flatten it.

Motion — calm-confident

TokenValueJob
--dur-quick240msfeedback: hover, press
--dur-base380msreveals, moves
--dur-slow520mshero: count-ups, the gate
--ease-outcubic-bezier(.22,.9,.24,1)default deceleration

Signatures: numerals count up (the instrument settles) · ticks draw in sequence · fields breathe (ambient, subtle) · reveals stagger 40–70ms. Never bounce; never linear. Reduced-motion zeroes the tokens — the page must read fully static.
